Privacy Policy

Last updated: October 5, 2026

This Privacy Policy explains how the IRCM Discord bot processes and stores information when it is used on the IRCM Discord server. The bot uses this data only for the server features described below.

1. Data We Process

Discord account and member information

  • Discord user ID, username, display name, and nickname
  • Roles, avatar information, account creation date, and server join date
  • Guild and channel identifiers

Message data

In channels and features where the bot operates, it may process message content, message IDs, author information, links, attachments, and embeds. This data is used for moderation, logging, tickets, help threads, and other server features that depend on normal Discord messages.

Presence information

The bot processes online, idle, Do Not Disturb, and offline or last-seen information for member-information features.

Support and moderation information

This can include ticket conversations, moderation events, server event logs, role or nickname changes, and help-thread history.

AI assistant data

When a user talks to the AI assistant, the bot processes the user's prompt and relevant conversation context. AI conversation history is stored locally so later replies can use previous messages.

2. How We Use Data

  • Moderate messages and detect prohibited, suspicious, or unsafe content
  • Investigate incidents, reports, disputes, and moderation actions
  • Create, operate, and review support tickets
  • Maintain help-thread archives while the related thread exists
  • Keep server and moderation logs
  • Provide member information, including presence and last-seen information
  • Operate bot commands and other server features
  • Generate AI responses when a user chooses to use the AI assistant

Moderation and server logs, as well as closed ticket histories, are kept for up to 90 days so server staff can review what happened on the server, investigate violations, check moderation actions, resolve disputes, review reports, and handle security or support issues.

3. Message Content

The bot may automatically read message text, links, attachments, and embeds in relevant Discord channels. This is required for moderation rules, server logging, ticket handling, help-thread archives, and other configured server features that operate on normal messages.

There is no individual opt-out from server-side message processing used for moderation, logging, tickets, or help threads. These systems apply to messages posted in the relevant server channels. Use of the AI assistant is optional, and a user can stop sending new data to an AI provider by not using that feature.

4. Presence Data

The bot uses online, idle, Do Not Disturb, and offline or last-seen status information for member information, including the /info command. It does not use games, Spotify activity, custom status, device status, or activity history for this feature.

The bot stores the current status or a last-seen timestamp locally. There is no user-level opt-out for presence tracking. Presence records are removed when a member leaves the server, and stale records are cleaned up by the bot.

5. Data Storage and Retention

Some data is stored locally on the system where the bot runs. The current retention rules are:

DataRetention
Moderation and server logsUp to 90 days
Closed ticket historiesUp to 90 days
AI conversation historyUntil the user runs /clear_history or an applicable deletion request is processed
Presence and last-seen dataWhile the member remains on the server; removed when the member leaves, with stale records also cleaned up
Help-thread archiveWhile the related Discord help thread exists; the local archive is removed when that thread is deleted

These retention periods apply to copies stored by the bot. They do not delete messages or other content directly from Discord.

6. AI Assistant and Third-Party Providers

When a user sends a prompt to the AI assistant, the prompt and relevant conversation context may be sent to a third-party AI provider configured by the bot. This is used only to generate a response to the user's request.

The bot may use different third-party AI providers depending on its current configuration. Data is sent only to the provider selected for that request and is not automatically sent to every supported provider.

The bot does not use Discord message content to train or fine-tune AI models and does not create training datasets from Discord messages. Third-party AI providers process the data sent to them according to their own privacy policies and terms.

7. Data Sharing

The bot does not sell Discord data and does not use it for advertising or marketing analytics.

Data may be sent or exposed outside the bot only when needed for a feature, including:

  • Discord, as part of normal bot operation through Discord's APIs
  • The AI provider selected by the bot when a user uses the AI assistant
  • External services used by moderation or other configured features to retrieve, download, or check user-provided links or attachments

8. Data Deletion

AI conversation history

Users can delete their stored AI conversation history at any time with /clear_history. This command removes the AI history stored for that user. It does not remove unrelated moderation logs, ticket records, help-thread records, or other server data.

Other stored data

For requests involving other data stored by the bot, a user can open a support ticket on the IRCM Discord server and request deletion of data associated with their Discord account. The request is reviewed and processed manually.

Moderation/server logs and closed ticket histories are deleted no later than 90 days after they are stored. A deletion request may result in applicable records being removed sooner when they are no longer needed for an active moderation, security, support, or dispute-related issue.

9. User Choices

  • AI conversation history can be deleted with /clear_history.
  • Other applicable data-deletion requests can be submitted through a support ticket on the IRCM Discord server.
  • There is no user-level opt-out for presence tracking.
  • There is no user-level opt-out from automatic moderation and other server-side message processing in relevant channels.
  • Users can stop new AI-provider transmissions by no longer using the AI assistant.

10. Security

Stored bot data is kept on the system used to operate the bot. Access to that data is intended for bot administration, moderation, support, and maintenance. No storage or security system can guarantee absolute protection against unauthorized access.

11. Changes to This Privacy Policy

This policy may be updated when the bot's features or data practices change. The latest version will be published on this page with an updated revision date.

12. Contact and Privacy Requests

For privacy questions or requests to delete data associated with a Discord account, open a support ticket on the IRCM Discord server and state that the ticket is a privacy or data-deletion request.
